# 🌹 Almas de Pombagira — Portal Místico Interativo

**Almas de Pombagira** é um portal artístico, cultural e interativo dedicado ao estudo simbólico, estético e espiritual das Pombagiras.  
O projeto combina **design místico cinematográfico**, **animações avançadas**, **conteúdo informativo** e um **quiz interativo**, criando uma experiência imersiva e respeitosa.

---

## 🔮 Visão Geral

Este projeto foi desenvolvido como um **site completo em arquivo único (HTML + CSS + JavaScript)**, ideal para hospedagem via **GitHub Pages**.

O portal reúne:

- Quiz interativo: *Descubra sua Pombagira*
- Apresentação das principais Pombagiras
- Mensagens espirituais rotativas
- Central de redes sociais
- Estética ritualística e simbólica avançada

## ✨ Funcionalidades Principais

### 🔮 Quiz Interativo
- Sistema de perguntas progressivas
- Barra de progresso animada
- Resultado final personalizado
- Interface responsiva e imersiva

### 👑 Entidades Apresentadas
- Maria Padilha  
- Rosa Caveira  
- Maria Mulambo  
- Dama da Noite

Cada entidade possui:
- Descrição simbólica
- Domínios espirituais
- Cores e oferendas
- Identidade visual própria

### 💭 Mensagem do Dia
- Frases rotativas atribuídas às Pombagiras
- Atualização automática a cada carregamento
- Mensagem espiritual com saudação ritualística

### 🌹 Central de Redes Sociais

- Instagram
- YouTube
- Kwai
- Pinterest

- Threads

Tudo integrado em um layout visual coeso e animado.

## 🎨 Design & Experiência Visual

- Gradientes místicos animados
- Partículas flutuantes (roxo, vermelho e dourado)
- Efeitos de fumaça, brilho e velas
- Tipografia ritualística (Cinzel, Playfair Display, Cormorant Garamond)
- Interface totalmente responsiva
- Scrollbar personalizada
- Animações suaves com CSS puro

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3 avançado (animações, gradientes, efeitos visuais)**
- **JavaScript puro (Vanilla JS)**
- **Google Fonts**
- **GitHub Pages** (deploy)

> Nenhum framework externo foi utilizado. Todo o projeto é independente e leve.
